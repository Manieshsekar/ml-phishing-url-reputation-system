# ML Phishing URL Reputation System

A machine learning based phishing URL detection system with SQL-backed URL reputation and scan history.

## Project Objective

The system analyzes URL characteristics using machine learning to classify URLs as legitimate or phishing and maintains a SQL-backed reputation and scan history system.

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- SQL
- Streamlit
- Git/GitHub
